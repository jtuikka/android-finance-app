
**Stack**
- Kotlin + Jetpack Compose (Material 3)
- MVVM + Repository
- Room + Flow
- Hilt DI
- Navigation-Compose

**Features (MVP)**
- Seed categories on first launch
- Home: month totals (income/expense/net) + top expense categories
- Add transaction: amount, type, category, note

## Run
1. Open in Android Studio
2. Gradle sync
3. Run `app`
